🌐 المرجع الشامل: جميع مميزات وتقنيات منصة EduHub Gaza
التوثيق الفني والوظيفي المتكامل لمنظومة مساحة العمل والتعليم الذكية الأولى في قطاع غزة

عن منصة EduHub Gaza: منظومة سحابية وإدارية حديثة متكاملة صُممت خصيصاً لإدارة وتشغيل أول وأكبر مساحة عمل وتعليم ذكية في قطاع غزة، تجمع بين الواجهة البرمجية المتطورة والتجهيزات الميدانية الصلبة لضمان بيئة إنتاجية متواصلة 100%.


======================================================================
🛠️ 1. التقنيات والمعمارية البرمجية المستخدمة (Tech Stack)
======================================================================


الطبقة (Layer) | التقنيات والمكتبات المستخدمة | الوظيفة والدور في المنصة
----------------------------------------------------------------------
واجهة المستخدم (Frontend) | Next.js 16.4 (App Router) + React 19.3 + TypeScript 5 + Turbopack | بناء واجهة تفاعلية فائقة السرعة، توجيه سلس بدون إعادة تحميل كامل، وأداء بناء وتحميل لحظي.
التصميم والواجهات (Styling) | Tailwind CSS v4 + Lucide React + clsx + tailwind-merge | تصميم عصري متجاوب 100% مع شاشات الهواتف واللابتوب، ونظام أيقونات حديث وموحد.
محرك اللغات والاتجاه | Custom LanguageContext (Ar/En) + RTL / LTR Dynamic Engine | دعم كامل وفوري للغتين العربية والإنجليزية مع تبديل الاتجاه والخطوط آلياً.
طبقة الحماية والوسيط | Next.js API Proxy Layer (/api/proxy) + Zod Schema Validation | عزل مفاتيح الـ API وحل مشاكل CORS والتحقق الصارم من صحة المدخلات قبل إرسالها.
الخادم والـ API (Backend) | Laravel 12 Framework + PHP 8.2+ + RESTful Architecture | معالجة منطق الأعمال (Business Logic)، التحكم بالصلاحيات، وإدارة الحجوزات والرصيد والعمليات الحساسة.
المصادقة والأمان | Laravel Sanctum + Bcrypt Encryption + Tokenized Links | جلسات توثيق مشفرة وحماية بنكية لكلمات المرور وتفعيل سري عبر روابط مؤقتة ذات استخدام وحيد.
قاعدة البيانات (Database) | MySQL / MariaDB + Eloquent ORM + ACID Transactions | جداول مترابطة بفهارس عالية السرعة، وضمان عدم حدوث تضارب في الرصيد أو الحجوزات.
بوابات الرسائل والبريد | Brevo REST API + Tweet SMS Gateway + WhatsApp Protocol | إرسال رسائل القبول والتأكيد عبر الإيميل، إرسال رسائل SMS جماعية، وتوليد نصوص ورسائل واتساب فورية.


======================================================================
🌟 2. بوابة الزوار والخدمات العامة (Public Features)
======================================================================


1. ميزة تصريح الزيارة اليومية السريعة (1-Day Visitor Pass)
--------------------------------------------------
* حل فوري ومنقذ للطوارئ: مخصص لمن يحتاج المساحة ليوم واحد فقط (امتحانات إلكترونية، مقابلات عمل عن بعد، تقديم فيزا أو مهمة عاجلة) دون الحاجة للاشتراك الشهري.
* تحديد إجباري ودقيق للموعد: اختيار دقيق لتاريخ وساعات الزيارة للتنسيق المسبق وضمان توفر المقاعد.
* تخصيص مقعد ذكي وتلقائي: عند اعتماد الطلب، يخصص النظام فوراً مقعداً شاغراً في القاعة المناسبة ويربطه برقم التصريح الرسمي (#VIS-XXXX).
* إشعار فوري مزدوج (WhatsApp + Email): تصل الزائر رسالة واتساب رسمية وإيميل معتمد يحتويان على رقم المقعد، ساعات الحجز، وإرشادات الدخول.
* حماية أولوية العضويات: يمنع النظام الأعضاء المسجلين من تقديم طلب زائر، ويوجههم لتسجيل الدخول للاستفادة الكاملة من مميزات عضويتهم.

2. ميزة التقديم الذكي للعضوية (Smart Membership Application)
--------------------------------------------------
* استمارة تسجيل إلكترونية بـ 3 خطوات: تسجيل سريع مع تحديد نوع العضوية (طالب جامعي / مستقل Freelancer).
* رفع المرفقات والإثباتات: إمكانية إرفاق صورة بطاقة الطالب أو إثبات العمل الحر مباشرة لمراجعتها من الإدارة.
* لوحة الفرز والتدقيق الإداري: فحص الطلبات، مراجعة البيانات، والقبول أو الرفض مع ذكر الأسباب بكل شفافية.

3. ميزة التفعيل الآمن وتعيين كلمة المرور (Self-Activation)
--------------------------------------------------
* رابط تفعيل سري ومحمي: عند قبول العضو، يرسل النظام رابط تفعيل فريد وذو صلاحية زمنية (Token-based URL) عبر البريد الإلكتروني.
* خصوصية تامة وحماية الحساب: يقوم العضو بنفسه باختيار وتعيين كلمة مروره الخاصة، دون أن يراها أو يتدخل بها أي موظف أو إداري.
* حماية ضد التكرار: إذا كان الحساب مفعلاً مسبقاً ولديه كلمة مرور، يمنع النظام إعادة إرسال روابط التفعيل ويوجهه مباشرة لصفحة الدخول.

4. الصفحة الرئيسية التفاعلية (Modern Landing Page)
--------------------------------------------------
* واجهة عصرية متكاملة: استعراض تعريفي بالمساحة، عدادات الإحصائيات الحية، خطط الأسعار والعضويات، وقسم الأسئلة الشائعة ونموذج التواصل.

======================================================================
💺 3. ميزة حجز المقاعد التفاعلي المباشر (Seat Booking System)
======================================================================

* خريطة مقاعد حية ومباشرة: شبكة تفاعلية تضم 20 مقعداً في كل قاعة مقسمة على 4 صفوف (5 مقاعد في كل صف)، تتحدث ألوانها فورياً بحسب اليوم والوقت المختار.
* فصل كامل ومراعاة تامة للخصوصية: صالة الإناث (Women Hall: FH-01..20) مستقلة بالكامل ومخصصة للطالبات والمستقلات، وصالة الشباب (Youth Hall: YM-01..20) مجهزة للعمل المستمر.
* حالات المقاعد الذكية بالألوان: 🟢 متاح بالكامل (جاهز للحجز بنقرة واحدة)، 🔵 محجوز جزئياً (مع خاصية الضبط التلقائي للساعات الشاغرة Smart Autofill)، ⚪ غير متاح (محجوز بالكامل)، 🔒 مقفل إدارياً (للصيانة أو طارئ).
* مؤشر الكهرباء المباشر (⚡ Zap): علامة تؤكد أن المقعد متصل بمنفذ طاقة نشط ومستمر 24/7 مستمدة من حقل has_power = true.
* محرك منع التضارب الرياضي: استحالة حجز المقعد لنفس الساعة لمستخدمين مختلفين عبر خوارزمية فحص التداخل الزمني بالدقيقة.
* فترات تشغيلية قياسية: 7 فترات تشغيلية يومياً من الساعة 09:00 صباحاً حتى 04:00 عصراً مقسمة بالساعة.
* ضمان المقعد المسبق: يضمن العضو مقعده المحجوز باسمه قبل الحضور بدون أي عشوائية.

======================================================================
👤 4. بوابة لوحة تحكم العضو (Member Portal Features)
======================================================================

* إدارة الرصيد والحصص الشهرية (Rolling Quotas): عرض إجمالي الساعات المتاحة، المستهلكة، والمتبقية في اشتراك العضو لحظة بلحظة.
* إدارة ومتابعة الحجوزات وإلغاؤها: سجل كامل بجميع الحجوزات القادمة والسابقة مع إمكانية إلغاء الحجز إلكترونياً واسترجاع الساعات تلقائياً للرصيد دون تدخل بشري.
* معرض إنجازات الأعضاء (Portfolio): مساحة خاصة لكل عضو لنشر مشاريعه ونجاحاته وصور أعماله ومشاركتها مع مجتمع EduHub لبناء شبكة علاقات مهنية.
* مركز الدعم الفني والتذاكر المباشرة: إمكانية فتح تذكرة دعم فني أو اقتراح من داخل الحساب ومتابعة ردود الإدارة حتى حل المشكلة.
* أمان الحساب: إمكانية تعديل كلمة المرور والبيانات الشخصية بسهولة وأمان.

======================================================================
⚙️ 5. لوحة التحكم والإدارة المركزية (Admin Control Center)
======================================================================

* لوحة المراقبة العامة وعداد الإشغال الحي: رؤية فورية لعدد المتواجدين داخل الصالات الآن، ونسبة الإشغال لمنع الاكتظاظ، والإحصائيات التشغيلية اليومية.
* الحجز الإداري السريع: إمكانية قيام موظف الاستقبال بحجز مقعد لعضو قادم مباشرة في ثوانٍ.
* تسجيل الحضور والانصراف الرقمي (QR Attendance): تسجيل الحضور بلمسة واحدة برقم العضوية أو رمز الـ QR مع احتساب ساعات التواجد الفعلية ومطابقتها مع الحجوزات.
* إدارة المستحقات المالية والاشتراكات: متابعة اشتراكات الأعضاء، المبالغ المستحقة والمسددة، وتوثيق السداد بوضوح وشفافية.
* منظومة التعميمات والرسائل الجماعية (SMS Broadcasts Engine): إرسال رسائل وتنبيهات جماعية لكافة الأعضاء بضغطة زر عبر بوابة TweetSMS.
* إدارة تذاكر الدعم والطلبات: فرز وحل استفسارات وشكاوى الأعضاء والرد الفوري عليها.
* نظام التقارير والإحصائيات وتصدير البيانات: تقارير شاملة عن معدلات إشغال القاعات وتصدير البيانات لجداول Excel.

======================================================================
⚡ 6. التجهيزات الميدانية والفيزيائية للمساحة (On-Ground Specs)
======================================================================

* كهرباء مستمرة 24/7 دون انقطاع: منظومة طاقة شمسية هجينة ومولدات احتياطية ومنظومة UPS تضمن عدم انقطاع التيار نهائياً عن أجهزتك.
* إنترنت ألياف ضوئية (Fiber Optic) فائق السرعة: شبكة مخصصة للعمل عن بعد والاجتماعات ومكالمات الفيديو بدون تقطيع.
* منفذ كهرباء وشاحن مخصص لكل مقعد: استقلالية تامة دون الحاجة لمشتركات وتوصيلات إضافية.
* كراسي مكتبية طبية مريحة (Ergonomic Chairs): مصممة لدعم الظهر والفقرات لجلسات العمل والدراسة الطويلة.
* تكييف وهدوء صوتي تام: بيئة عمل مكيفة بالكامل مع سياسة صارمة للهدوء، بالإضافة لركن كافتيريا وضيافة مجهز.
