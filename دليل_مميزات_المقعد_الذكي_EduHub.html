💺 الدليل الهندسي والتقني الشامل

مواصفات ومميزات "المقعد الذكي" في منصة EduHub Gaza

التفاصيل الدقيقة لفيوتشر حجز المقاعد الرقمي، التجهيزات الميدانية، والتقنيات البرمجية المستخدمة

مفهوم المقعد الذكي في EduHub Gaza: المقعد في منصة EduHub ليس مجرد طاولة وكرسي، بل هو "محطة عمل متكاملة" (Smart Workstation) معرفة رقمياً في النظام ومجهزة ميدانياً لمواجهة تحديات الكهرباء والإنترنت والضوضاء، مما يضمن للمستفيد بيئة إنتاجية متواصلة 100%.

💻 1. الفيوتشرز والخصائص الرقمية للمقعد (Digital & System Features)

🗺️

1. خريطة المقاعد الحية والتفاعلية (Live Interactive Seat Map)

  • عرض مرئي فوري: شبكة تفاعلية منظمة (Grid) تعرض 20 مقعداً في كل قاعة مقسمة على 4 صفوف (كل صف 5 مقاعد).
  • تحديث لحظي للحالة: تتغير ألوان المقاعد وتفاصيلها بناءً على التاريخ والفترة الزمنية المحددة في ثوانٍ.
  • مراعاة خصوصية الصالات:
    • صالة الشباب (Youth Hall): 20 مقعداً بكود يبدأ بـ YM-01 حتى YM-20.
    • صالة الإناث (Women Hall): 20 مقعداً مخصصة ومستقلة بالكامل بكود FH-01 حتى FH-20.
🎨

2. حالات المقعد الذكية والألوان الدلالية في النظام

الحالة المظهر واللون المعنى البرمجي والتجربة
متاح بالكامل خلفية خضراء وحدود زمردية المقعد شاغر تماماً طوال الفترة المختارة وجاهز للنقر والحجز الفوري.
محجوز جزئياً خلفية زرقاء فاتحة المقعد محجوز في بعض ساعات الوردية ولكنه متاح في ساعات أخرى؛ يتيح النظام حجز الساعات الشاغرة بضغطة زر.
غير متاح / محجوز رمادي غير مفعل (Disabled) المقعد محجوز بالكامل في هذه الفترة ولا يمكن النقر عليه لمنع التضارب.
مقفل / صيانة أيقونة قفل صفراء/برتقالية المقعد مقفل إدارياً لأسباب فنية أو صيانة الكرسي أو فحص الكهرباء.
⚡

3. مؤشر الطاقة الكهربائية النشط (Active Power Indicator)

  • شعار الطاقة المباشر: كل مقعد على الخريطة يظهر بجانبه أيقونة البرق الذهبية (⚡ Power Ready) والتي تعكس حقل has_power = true في قاعدة البيانات، للتأكيد للمستخدم أن هذا المقعد مزود بمنفذ كهرباء شغال.
⏱️

4. إدارة الفترات الزمنية ومنع التضارب الرياضي (Collision Detection)

  • 7 فترات تشغيلية يومية: من الساعة 09:00 صباحاً حتى 04:00 عصراً (تقسيم دقيق بالساعة).
  • محرك فحص التداخل: يضمن النظام معادلة رياضية صارمة: لا يمكن لأي مستخدمين اثنين حجز نفس المقعد في نفس الدقيقة.
  • ميزة التعبئة الذكية للساعات الشاغرة (Smart Time-Slot Autofill): إذا اختار المستخدم مقعداً محجوزاً جزئياً، يقوم النظام تلقائياً بتعديل توقيت الحضور والانصراف إلى أول فترة شاغرة متاحة للمقعد!
🎫

5. تخصيص المقعد الآلي لتصاريح الزوار اليومية (Visitor Desk Assignment)

  • حجز ذكي للزائر: عند قبول الإدارة لطلب الزيارة اليومية (Visitor Pass)، يقترح النظام تلقائياً مقعداً شاغراً ومناسباً لجنس الزائر وتوقيت زيارته.
  • حفظ المقعد على التصريح: يتم حفظ seat_number و room_id في سجل التصريح مباشرة ويظهر فوراً في جدول الحجوزات كأنه مقعد مشغول، مما يمنع حجزه من قِبل أي عضو آخر.
📲

6. إشعارات تأكيد المقعد الرسمية (WhatsApp & Email Dispatch)

  • تأكيد برقم المقعد المحدد: رسالة القبول الموجهة للزائر أو العضو تحتوي بشكل صريح على:
    • رقم المقعد واسم القاعة: (مثال: 💺 المقعد المخصص لك: مقعد 5 - صالة الشباب).
    • ساعات الحجز وتاريخه: (مثال: من 09:00 ص إلى 01:00 م).
    • كود الحجز الرقمي: كود رسمي للتحقق منه عند بوابة الاستقبال.

⚡ 2. التجهيزات الميدانية والفيزيائية للمقعد (On-Ground Specs)

🔋

منفذ كهرباء مخصص 24/7

كل مقعد مزود بقابس كهرباء مدمج (Power Socket) متصل مباشرة بشبكة طاقة شمسية هجينة ومولدات مركزية ونظام UPS، لمنع إغلاق اللابتوب أو فقدان العمل أثناء انقطاع التيار العمومي.

🌐

إنترنت فايبر عالي السرعة

تغطية شبكة Wi-Fi 6 قوية وموجهة تصل لكل مقعد بمعدل استقرار فائق وسرعة رفع وتنزيل عالية تضمن إجراء اجتماعات Zoom وGoogle Meet دون أي تقطيع في الصوت أو الصورة.

🪑

كرسي مكتبي مريح (Ergonomic)

كراسي مكتبية مصممة هندسياً لدعم الظهر والفقرات (Lumbar Support) مع إمكانية تعديل الارتفاع ومساند الذراعين، لتوفير أقصى درجات الراحة أثناء ساعات العمل والدراسة الطويلة.

📐

طاولة عمل متسعة ومستقلة

مساحة مكتبية واسعة تتسع للابتوب، شاشة خارجية، دفاتر، وفأرة، مع مسافات فاصلة مدروسة بين المقاعد لمنح كل شخص مساحته وخصوصيته الشخصية.

💡

إضاءة مريحة للعين

توزيع ضوئي هندسي مدروس يمنع الانعكاس على شاشات الأجهزة ويقلل إجهاد العين والصداع أثناء القراءة والبرمجة المستمرة.

❄️

تكييف وهدوء صوتي

بيئة مكيفة صيفاً ودافئة شتاءً مع عزل صوتي وسياسة صارمة للهدوء لمنع المقاطعات والحفاظ على أعلى درجات التركيز.

🛠️ 3. التقنيات والـ Stack المستخدم في برمجة ميزة المقاعد

المستوى (Layer) التقنيات المستخدمة الدور والوظيفة في ميزة المقاعد
الواجهة الأمامية (Frontend) Next.js 16 (App Router) + React 19 + Tailwind CSS بناء واجهة المقاعد التفاعلية، تحديث الألوان الفوري للمقاعد، التجاوب مع شاشات الهواتف واللابتوب، واستخدام أيقونات Lucide (Armchair, Zap, Clock).
الواجهة الخلفية (Backend) Laravel 11 REST API + PHP 8.2+ معالجة طلبات الحجز، خوارزمية فحص التوفر بالدقيقة، ونقاط النهاية (API Endpoints):
• /api/room-seats/overview
• /api/visitor-passes/{id}/available-seats
قاعدة البيانات (Database) MySQL / MariaDB + Eloquent ORM جداول مترابطة بمفاتيح أجنبية وفهارس سريعة:
• seats (room_id, seat_number, code, has_power, is_locked, status)
• rooms (room_key, name_ar, gender, capacity)
• bookings (user_id, seat_id, booking_date, start_time, end_time)
• visitor_passes (seat_id, room_id, seat_number, visit_date)
بوابات الإشعار والرسائل Brevo API + WhatsApp API Protocol توليد وإرسال رسائل التأكيد الرسمية المخصصة التي تحتوي على رقم المقعد ورابط إرشادات الوصول.
