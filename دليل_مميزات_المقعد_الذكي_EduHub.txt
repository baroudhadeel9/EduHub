💺 الدليل الشامل: مواصفات ومميزات "المقعد الذكي" في منصة EduHub Gaza
التوثيق الهندسي والتقني لخصائص محطة العمل (The Smart Workstation)
======================================================================

مفهوم المقعد الذكي في EduHub Gaza:
المقعد ليس مجرد طاولة وكرسي، بل محطة عمل رقمية ومادية متكاملة، معرفة برمجياً
في النظام لمنع التضارب ومجهزة ميدانياً لمواجهة تحديات الكهرباء والإنترنت.


💻 1. الفيوتشرز والخصائص الرقمية للمقعد على الموقع (Digital Platform Features)
----------------------------------------------------------------------
1. خريطة المقاعد التفاعلية الحية (Interactive Live Seat Map):
   - شبكة مقاعد منظمة (Grid) تعرض 20 مقعداً في كل صالة (4 صفوف × 5 مقاعد).
   - تحديث لحظي للألوان والحالات بناءً على التاريخ والفترة الزمنية المحددة.
   - صالات مستقلة للخصوصية:
     * صالة الشباب (Youth Hall): كود المقاعد YM-01 إلى YM-20.
     * صالة الإناث (Women Hall): كود المقاعد FH-01 إلى FH-20 (مستقلة تماماً).

2. حالات المقعد الذكية وألوانها الدلالية في النظام:
   - متاح بالكامل (🟢 Fully Available): لون أخضر زمردي، جاهز للحجز فوراً.
   - محجوز جزئياً (🔵 Partially Booked): لون أزرق سماوي، متاح في ساعات معينة ومحجوز في أخرى.
   - غير متاح / محجوز بالكامل (⚪ Unavailable): لون رمادي، غير قابل للنقر لمنع التضارب.
   - مقفل / صيانة (🔒 Locked): قفل إداري أو صيانة فنية للكرسي أو الكهرباء.

3. مؤشر الطاقة الكهربائية النشط (Active Power Indicator ⚡):
   - كل مقعد يحمل أيقونة البرق (Zap) المعبرة عن has_power = true في النظام، لتأكيد وصول الكهرباء للمقعد.

4. نظام الفترات الزمنية ومنع التضارب الرياضي (Collision Detection):
   - 7 فترات تشغيلية يومياً من 09:00 صباحاً حتى 04:00 عصراً مقسمة بالساعة.
   - معادلة برمجية تمنع حجز المقعد لنفس الدقيقة لمستخدمين مختلفين.
   - التعبئة التلقائية الذكية (Autofill): إذا نقر العضو على مقعد محجوز جزئياً، يضبط النظام الوقت تلقائياً على أول فترة شاغرة متاحة للمقعد!

5. تخصيص المقعد الآلي لتصاريح الزوار (Visitor Desk Allocation):
   - عند اعتماد الإدارة لطلب تصريح الزيارة اليومية (1-Day Pass)، يخصص النظام مقعداً شاغراً فوراً.
   - يُثبت المقعد في سجل التصريح ويُسجل كأنه مشغول لمنع تضارب الأعضاء معه.

6. إشعارات المقعد عبر واتساب والإيميل (WhatsApp & Email Dispatch):
   - إشعار فوري يحتوي على:
     * رقم المقعد واسم القاعة (مثال: مقعد 5 - صالة الشباب).
     * ساعات وتاريخ الحجز الدقيقة.
     * كود الحجز أو التصريح الرسمي.


⚡ 2. التجهيزات الميدانية والفيزيائية للمقعد (On-Ground Facilities)
----------------------------------------------------------------------
* منفذ كهرباء وشاحن مخصص 24/7 لكل مقعد:
  قابس مباشر متصل بنظام طاقة شمسية هجين ومولدات وUPS لحماية اللابتوب ومنع انقطاع التيار نهائياً.

* إنترنت فايبر مخصص وفائق السرعة:
  تغطية Wi-Fi 6 ممتازة تغطي كافة المقاعد بسرعة رفع وتنزيل عالية لمكالمات الفيديو والاجتماعات بدون تقطيع.

* كرسي مكتبي مريح وصحي (Ergonomic Chair):
  دعم لفقرات الظهر (Lumbar Support) مع إمكانية تعديل الارتفاع لجلسات عمل طويلة ومريحة.

* طاولة عمل واسعة ومستقلة:
  مساحة كافية للابتوب، شاشة إضافية، وماوس، مع مسافات فاصلة تضمن الخصوصية وراحة الحركة.

* إضاءة مريحة للعين وتكييف هوائي:
  إضاءة مكتبية مدروسة تمنع الانعكاس وإجهاد العين، وبيئة هادئة ومكيفة بالكامل.


🛠️ 3. التقنيات والبنية البرمجية المستخدمة في ميزة المقاعد (Tech Stack)
----------------------------------------------------------------------
* Frontend:
  - Next.js 16 (App Router) & React 19.
  - Tailwind CSS للتصميم والتجاوب.
  - Lucide Icons (Armchair, Zap, Clock).

* Backend & API:
  - Laravel 11 REST API & PHP 8.2+.
  - Endpoints: /api/room-seats/overview & /api/visitor-passes/{id}/available-seats.

* Database:
  - MySQL / MariaDB مع Eloquent Models: Seat, Room, Booking, VisitorPass.
  - مفاتيح ربط وفهارس دقيقة للأداء السريع.

* Notification Integration:
  - Brevo API لإرسال الإيميلات المعتمدة بتفاصيل المقعد.
  - WhatsApp API لتوليد رسائل القبول الفورية.
